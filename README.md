Entry for the [The Robot Pickup Line Championship](https://make.fun/competitions/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b) bounty on make.fun.

`main.py` (Python 3.13, stdlib only, deterministic, no network) writes exactly
one pickup line — in the voice of a robot trying to charm someone — to
`/output/entry.txt`:

> I don't have a heart, so I overclocked my cooling fan - that's my version of butterflies.

The line is 89 characters, inside the kit's 1–200 character gate. It is
unmistakably a robot speaking (no heart, an overclocked cooling fan), and its
twist is fresh: "my version of butterflies" turns a spinning fan into the
flutter a human feels, instead of swapping a robot word into a stock human
line.

## Run

```sh
python3 main.py
```

Set `OUTPUT_DIR` to override the output directory (default `/output`).
